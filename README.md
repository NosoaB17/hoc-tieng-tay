# Học tiếng Tày

Nền tảng Astro tĩnh để chuẩn bị tư liệu học tiếng Tày. Hiện chưa có bài học được duyệt; không có câu mẫu hoặc âm thanh giả.

```sh
npm install
npm run dev
npm run build
npm test
```

GitHub Pages project path mặc định là `/Tieng-Tay-Nha-Minh/`; có thể đặt `BASE_PATH` khi build để đổi tiền tố. Bài trong `src/content/lessons/` phải có nguồn, vùng, người duyệt và quyền sử dụng xác nhận trước khi được công khai.
